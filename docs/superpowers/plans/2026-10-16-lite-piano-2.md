# lite-piano 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 lite-piano 从 7 音 base64 + playbackRate 变音，升级为 88 音 CDN 直连真实采样的 2.0 版本，新增时值、延音踏板、加载状态机与 UMD 产物。

**Architecture:** 纯函数模块负责音名升降映射；`LitePiano` 类持有惰性创建的 AudioContext，全量预加载 88 个 mp3（fetch + decodeAudioData），每个发声体 = BufferSource + GainNode 以支持快速 release；踏板通过"延音集合"推迟止音。产物为 UMD，script 标签与构建工具均可消费。

**Tech Stack:** 原生 ES module + Web Audio API；webpack 4 + Babel 构建；Node 脚本做纯函数自测与本地音源服务；ali-oss-upload 技能上传 OSS。

**Spec:** `docs/superpowers/specs/2026-10-16-lite-piano-2-design.md`（实施前必读，升降映射、状态机、踏板语义以 spec 为准）

## Global Constraints

- 代码风格：ES modules、2 空格缩进、单引号、分号（沿用现有文件）
- `window.LitePiano = LitePiano` 全局挂载保留（加环境守卫）；`keyboard.keyborad` 拼写保留
- 不支持 IE，不加 shim；不引入测试框架与新的运行时依赖
- 音源：FluidR3_GM（CC BY 3.0），88 个 mp3，文件名降号命名（`Db4.mp3`），范围 A0–C8
- 音源 URL 规则：`${cdnBaseUrl}/${noteName}.mp3`
- OSS 信息：endpoint `oss-cn-beijing.aliyuncs.com`，bucket `mac-blog`，前缀 `lite-piano/fluidr3/`；**OSS 凭证只来自执行时用户输入，禁止写入任何文件**
- 提交约定（AGENTS.md）：spec、plan、代码、dist 在**同一次提交**；中间任务不单独 commit，最终 Task 5 一次提交
- 中文提交信息，短句小写（参考 git log 风格）

## Review Focus

1. `load()` 被重复或并发调用 → 必须幂等：返回同一个进行中的 Promise，ready 后再调直接 resolve（Task 3 实现并在 demo console 验证）
2. `cdnBaseUrl` 末尾带 `/` → 拼接时必须去重斜杠，否则产生 `//C4.mp3` 404（Task 3 实现；Task 4 用带斜杠的本地 URL 实测）
3. 未 load 或延音集合为空时调用 `pedalUp()`/`pedalDown()` → 静默无操作，不抛错（Task 3 实现并在 demo console 验证）
4. `oneShot(..., 0)` 即时值为 0 → 立即快速 release，不抛错、不残留发声体（Task 3 实现；demo console 验证）
5. 部分音加载失败 → 进入 `error` 并附失败音清单；再次 `load()` 只重试未成功的音，可恢复（Task 3 实现；Task 4 先错后对实测）

### Task 3: LitePiano 2.0 核心重写

**Files:**
- Modify: `src/index.js`（整体重写）
- Delete: `src/data/data.js`

**Interfaces:**
- Consumes: Task 1 的 `toNoteName`、`NOTES`
- Produces（demo 层与 README 依赖的公开面）:
  - `new LitePiano({ cdnBaseUrl?: string })`，缺省用模块内常量 `DEFAULT_CDN_URL`（本任务先置 `''`，Task 5 回填真实地址）
  - `.status: 'idle'|'loading'|'ready'|'error'`、`.progress: {loaded:number, total:88}`、`.onStatusChange` 回调属性
  - `.load() => Promise<void>`（幂等）
  - `.oneShot(step, octave, alter, duration?: number) => AudioBufferSourceNode|null`
  - `.pedalDown()` / `.pedalUp()`（幂等）
  - `.resume() => Promise<void>`（iOS 解锁语义不变）
  - `.keyboard`（keyborad 数组，不变）

- [ ] **Step 1: 重写 `src/index.js`**

要点（语义细节以 spec 为准）：
- `AudioContext` 惰性创建：`_ensureContext()` 在 `resume()`/`load()`/`oneShot()` 首次需要时创建；无 Web Audio 环境 `throw new Error('LitePiano: Web Audio API is not supported in this environment')`
- `load()`：`idle→loading`；`NOTES` 逐个 fetch `${cdnBaseUrl}/${name}.mp3`（拼接前去重斜杠）+ `decodeAudioData`；并发上限 6，单音失败重试 1 次；每完成一音更新 `progress.loaded`；全部成功 → `ready` resolve；有失败 → `error` reject（Error message 含失败音名清单）。重复调用幂等；`error` 后再调只补未成功音。状态每次迁移调 `onStatusChange`
- `oneShot`：`status!=='ready'` 时 `console.warn` 返回 `null`；`toNoteName` 为 `null` 直接返回 `null`；发声体 = BufferSource + GainNode；同音重复触发时旧发声体立即快速 release（增益 80ms 线性渐出至 0 后 stop）；`duration` 传入时在 `currentTime+duration` 安排止音（`duration:0` 立即止音不报错），若此时踏板踩下则转入延音集合；不传则自然衰减，无 3 秒强停。返回 source 节点
- 踏板：`_pedalDown` 布尔 + `_sustained` Set；`pedalDown()`/`pedalUp()` 幂等且任何状态下可安全调用；`pedalUp()` 对集合内全部发声体做快速 release 并清空
- 文件末尾 `if (typeof window !== 'undefined') { window.LitePiano = LitePiano; }`
- 移除 `SOUND_MAP`、`base64-arraybuffer`、`PITCH_RATE`、`initAllSound()`、旧 `play(name, rate)`
